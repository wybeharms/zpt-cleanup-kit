# Intake questions

Ask these after the quick orientation, in one compact batch. Skip anything already answered.

1. What outcome matters most right now?
   - remove a few unused applications or large items;
   - free meaningful storage;
   - make selected folders easier to understand;
   - understand the whole Mac;
   - something more specific.
2. Should the agent recommend the smallest suitable cleanup package, or has the person already chosen one?
3. Is the goal a read-only report, or may the agent later propose changes for separate approval?
4. Is any folder, account, application, or category off limits for inspection?
5. Should explanations stay extremely brief, or include a little teaching when unfamiliar Mac concepts appear?

Do not ask for a list of every important application or file. That question is too broad to answer reliably. Discover stale-looking candidates, classify them, and ask focused follow-ups such as:

- “Fork has not been used recently and no running process or command link was found. Does the person still use it?”
- “This old Python environment depends on Python 3.11. Is the surrounding project still needed?”
- “This folder looks like a redundant code copy, but it also contains two contract documents. Should only the code be considered?”

An uncertain answer means Hold, not Remove.
